# Источник AI-истории

[ai-history.md](ai-history.md) — подлинный частичный экспорт пяти доступных
пользовательских Codex-сессий этого проекта: планирование/реализация, доработки
выбора времени, небольшая UI-правка, технический аудит/стабилизация и Requirements
Acceptance Audit с текущей документационной задачей. В заголовке архива приведены
имена исходных JSONL, SHA-256 снимков, количество сообщений и границы UTC.

Исходные 51 сообщение сверены с настоящим журналом: до редакции личных путей
они совпадали с его префиксом. Новый архив собран непосредственно из доступных
`response_item/message`, без восстановления по памяти. Сохранены user и видимые
commentary/final_answer, порядок сообщений внутри каждой сессии. Исторические
ошибки, планы и старые результаты не исправлялись под текущую реализацию.
Сессии сгруппированы по исходным журналам, а не перемешаны по времени.

Исключены system/developer, tool outputs, внутренние рассуждения, служебные
автоматические проверки разрешений и технический контекст интерфейса. Личные
пути заменены `[LOCAL_HOME]` и `[LOCAL_TEMP_PATH]`; это обозначенная редакция для
приватности. Секреты, ключи, токены, пароли, email и телефонные контакты в
экспортируемом тексте при проверке не обнаружены. Публичные ссылки проекта сохранены.

[initial-request.txt](initial-request.txt) — исходное текстовое вложение без
реконструкции. Доступные исходные текстовые вложения включены в конец архива.
Видео, изображения и PDF задания в текстовый экспорт не входят.
Полнота всех AI-взаимодействий не заявляется: архив ограничен доступными снимками,
финальный ответ текущей задачи и последующие сообщения отсутствуют.

Для отдельного настоящего журнала исходный экспортёр доступен командой:

```bash
python3 scripts/export-ai-history.py /absolute/path/to/session.jsonl --output /tmp/session-history.md
```

Этот экспортёр обрабатывает одну сессию и не редактирует личные пути. Публичный
сводный архив дополнительно фильтруется по описанным выше правилам. Перед любым
следующим обновлением требуется проверить новые сообщения и личные данные.
Нельзя подставлять чужой журнал или сочинять недостающую переписку. Decision log
и PLAN не заменяют реальные сообщения. SHA-256 в архиве относится к исходным
снимкам до фильтрации и редакции, а не к опубликованному Markdown.
