# Источник AI-истории

[ai-history.md](ai-history.md) содержит реальный частичный экспорт текущей
Codex-сессии, включая первоначальное планирование, архитектурные review,
согласованный план, M1 и доступные сообщения текущей реализации.

Вложения не реконструировались: [initial-request.txt](initial-request.txt) —
побайтовая копия исходного пользовательского текстового вложения. PDF задания
не включён в репозиторий: доступен в исходных материалах пользователя.

Экспорт содержит только фактически записанные видимые сообщения; исключены
технические события, tools, внутренние рассуждения, system/developer инструкции.
В заголовке экспорта указаны граница и SHA-256 снимка исходного JSONL. Это
частичный артефакт, не заявление о полноте истории. Ответ после последнего
экспорта и будущие сообщения появятся только при повторном экспорте.

Воспроизводимый экспорт из собственного доступного журнала:

```bash
python3 scripts/export-ai-history.py /absolute/path/to/current-session.jsonl
```

Не подставляйте журнал другого чата. Скрипт читает только явно переданный файл;
он не ищет другие сессии. Перед внешней сдачей проверить личные пути/сведения и,
если нужен полный экспорт интерфейса, приложить его дополнительно. Decision log
и PLAN не заменяют переписку. Отсутствующие реплики не добавляются по памяти.

Исходные Markdown-пробелы и переводы строк сохранены; `.gitattributes` отключает
для этих двух архивных файлов преобразование строк и whitespace-предупреждения.
Содержимое старых сообщений не исправляется под текущую реализацию.
